Install in a minute

Aries is free. No account, no ads.

  1. Download the latest .zip from the button above and double-click it.
  2. Drag “Aries Dynamic Island” into your Applications folder.
  3. First launch: right-click the app and choose Open, then Open again. (macOS asks this once because the app isn't from the App Store.) If it still won't open, go to System Settings → Privacy & Security and click Open Anyway.
  4. Or use Homebrew: 
    brew trust maxxforgestudio-del/tap
brew install --cask maxxforgestudio-del/tap/aries-dynamic-island
